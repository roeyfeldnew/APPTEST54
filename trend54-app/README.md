# TREND54 - הוראות הרצה עצמאיות (בלי מפתח, בלי כסף)

מדריך זה מיועד למי שאינו מפתח. כל השלבים מתבצעים דרך אתרים בדפדפן - **אין צורך בשום שורת פקודה (terminal)**.

---

## שלב א׳ - הורדת קבצי זיהוי הפנים (חד פעמי)

1. גשו לכתובת: https://github.com/vladmandic/face-api/tree/master/model
2. תראו רשימת קבצים. אתם צריכים להוריד **רק** את הקבצים ששמם מתחיל ב:
   - `tiny_face_detector_model`
   - `face_landmark_68_model`
   - `face_recognition_model`
   (לכל אחד מהם יש קובץ `-shard1` וקובץ `.json` - הורידו את כולם, בסך הכל כ-6 קבצים)
3. לכל קובץ: לחצו עליו ברשימה, ואז לחצו על כפתור ההורדה (חץ למטה / "Download raw file")
4. שמרו את כל הקבצים במחשב שלכם באיזור נגיש (למשל בתיקיית Downloads)

---

## שלב ב׳ - יצירת חשבון GitHub (חינם, 3 דקות)

1. גשו ל-github.com ולחצו Sign up
2. צרו חשבון עם מייל
3. לחצו על "+" בפינה העליונה → **New repository**
4. תנו שם לרפוזיטורי (למשל `trend54-app`), השאירו אותו **Public** או **Private** (שניהם חינם), ולחצו Create repository

---

## שלב ג׳ - העלאת קבצי הפרויקט ל-GitHub (בלי שורת פקודה!)

1. בתוך הרפוזיטורי החדש שיצרתם, לחצו על הקישור **"uploading an existing file"**
2. **גררו את כל תיקיית הפרויקט** (`trend54-app`, שקיבלתם ממני) לתוך החלון בדפדפן - GitHub תומך בגרירת תיקייה שלמה ושומר את המבנה הפנימי שלה אוטומטית
3. לפני שמאשרים - העתיקו את קבצי המודלים שהורדתם בשלב א׳ לתוך התיקייה `public/models` בפרויקט **לפני** הגרירה (כלומר: פתחו את תיקיית trend54-app במחשב, הכניסו את הקבצים לתיקיית `public/models`, ואז גררו את כל התיקייה)
4. גללו למטה ולחצו **Commit changes**

זהו - הקוד שלכם עכשיו ב-GitHub.

---

## שלב ד׳ - חיבור ל-Vercel (חינם, בלי כרטיס אשראי)

1. גשו ל-vercel.com ולחצו Sign Up
2. בחרו **"Continue with GitHub"** והתחברו עם אותו חשבון GitHub
3. לחצו **"Add New" → Project**
4. Vercel יציג את הרפוזיטורי `trend54-app` שיצרתם - לחצו **Import**
5. לפני שלוחצים Deploy, לחצו על **"Environment Variables"** והוסיפו שני משתנים (את הערכים תמצאו ב-Supabase, תחת Settings → API):
   - `NEXT_PUBLIC_SUPABASE_URL` → הערך מ-Project URL
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY` → הערך מ-anon public key
6. לחצו **Deploy**

אחרי כדקה-שתיים, Vercel ייתן לכם קישור חי לאתר (למשל `trend54-app.vercel.app`) - זהו, האתר באוויר.

---

## שלב ה׳ - הגדרת מסד הנתונים ב-Supabase (חד פעמי)

1. בפרויקט ה-Supabase שלכם, לכו ל-**SQL Editor** בתפריט הצד
2. פתחו את הקובץ `supabase/schema.sql` מהפרויקט שקיבלתם (אפשר לפתוח אותו בכל עורך טקסט, גם Notepad)
3. העתיקו את כל התוכן, הדביקו בתוך ה-SQL Editor ולחצו **Run**
4. לכו ל-**Storage** בתפריט הצד → **New bucket** → שם: `photos` → Public bucket: **כן** → Create

---

## שלב ו׳ - עדכון קוד בעתיד

בכל פעם שתרצו לעדכן משהו בקוד (או שאני אשלח לכם גרסה מעודכנת):
1. היכנסו לרפוזיטורי ב-GitHub
2. העלו את הקבצים המעודכנים באותה שיטה של גרירה (שלב ג׳)
3. Vercel יזהה את השינוי ויעדכן את האתר החי **אוטומטית** תוך דקה-שתיים - אין שום פעולה נוספת נדרשת
